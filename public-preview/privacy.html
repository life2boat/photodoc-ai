Политика обработки персональных данных

Какие данные обрабатывает сервис, зачем, как долго хранит и как удалить.

Проект документа. Описывает фактическую обработку данных в сервисе. Сведения об операторе и сроках хранения базы данных подтверждаются владельцем до публикации.

1. Оператор

Оператор персональных данных: наименование, ИНН, ОГРНИП, контакт для обращений: mdot22@yandex.ru.

2. Какие данные обрабатываются

КатегорияСоставЗачем

Реквизиты банковской карты обрабатывает платёжный сервис Robokassa; сервис их не получает и не хранит.

3. Правовые основания

  • исполнение договора оказания услуг (публичной оферты);
  • согласие субъекта данных, выраженное при оформлении заказа;
  • исполнение обязанностей, предусмотренных законодательством.

4. Сроки хранения и удаление файлов

  • после успешной передачи результата исходные файлы удаляются с сервера;
  • если передача результата не состоялась, файлы сохраняются для повторной попытки и удаляются после успешной доставки;
  • сведения о заказах хранятся в базе данных: срок подтверждается владельцем;
  • резервные копии могут содержать базу данных и файлы: срок хранения копий подтверждается владельцем.

5. Кому передаются данные

  • платёжный сервис Robokassa — для проведения оплаты;
  • Yandex.Disk — для передачи готовых файлов;
  • почтовый сервис — для отправки уведомлений.

Иным лицам данные не передаются, кроме случаев, предусмотренных законодательством.

6. Права субъекта данных

Вы вправе запросить сведения об обработке ваших данных, потребовать их уточнения, блокирования или удаления, а также отозвать согласие. Обращение направляется на mdot22@yandex.ru с указанием номера заказа.

7. Файлы cookie и аналитика

Информационная версия сайта не использует системы веб-аналитики и не устанавливает рекламные файлы cookie. При запуске сервиса на сайте может использоваться сервис статистики посещений; сведения об этом будут указаны здесь до запуска.

8. Защита данных

Доступ к файлам и базе данных ограничен сервисными учётными записями; передача данных между пользователем и сайтом выполняется по HTTPS. Меры, которые не реализованы, в этом документе не заявляются.
